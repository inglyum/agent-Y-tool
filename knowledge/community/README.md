# Community

Note ricavate dal gruppo Facebook xTool Official Italia e da altre community.
Servono a capire domande frequenti, problemi ricorrenti, applicazioni reali e
linguaggio degli utenti. **Non sono informazione ufficiale**: ogni voce va
etichettata come esperienza d'uso e, per specifiche, sicurezza, compatibilità
e garanzia, va confrontata con la documentazione xTool.

Formato consigliato (`<argomento>.yaml`):

```yaml
argomento: null
tipo: domanda_frequente | problema_ricorrente | applicazione | bisogno_emergente
descrizione: null
risposta_ufficiale: null     # con fonte xTool, se esiste
fonti: [fb_xtool_official_it]
data_rilevazione: null
```
